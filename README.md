# Better Player для Lampa

## Текущее состояние: 1.0.3

**Apple TV + Luxo + плеер tvOS Pro / Universal / Online:** плагин Lampa не получает внутренние события этих плееров. Перемотка удержанием и переход к следующей серии из Better Player в этом режиме **не реализованы**. Обновление не меняет это ограничение и не переключает выбранный плеер.

Исправлено в `better-player.js`:

- Варианты настроек передаются как объекты с понятными подписями, а не строка, разбираемая как отдельные символы. Повреждённые значения сбрасываются на допустимые.
- Укорочены названия; перенос текста ограничен настройками этого плагина.
- Добавлен статус: выбранный плеер, наличие событий видео и кнопок. Адреса потоков, токены и история не записываются в диагностику.
- Для внутреннего плеера: стрелки больше не перехватываются при навигации по кнопкам и меню; повторный запуск серии не размножает обработчики; исправлено распознавание строковых KeyboardEvent.code, смена направления и выход из удержания.
- Для внутреннего плеера: добавлен переход по событию окончания видео, с защитой от двойного переключения. OK, запускающий следующую серию, больше не передаёт последующий keyup кнопкам нового экрана.

### Установка и проверка

Используйте прежний адрес:

`https://evdokimovbusinez-code.github.io/lampa-better-player/better-player.js`

1. Полностью закройте Luxo и откройте снова.
2. В настройках Better Player должна быть версия **1.0.3**. Если осталась старая версия, удалите старую запись расширения и добавьте тот же адрес с `?v=103` в конце. Не оставляйте две записи.
3. Запустите фильм, вернитесь в настройки Better Player и посмотрите статус.
4. `tvos`, `tvospro`, `tvosl` и событие внешнего запуска означают нативный путь. Переключатели Better Player не могут добавить управление внутри этого плеера.

Внутренний плеер Lampa — отдельный режим, со своими ограничениями форматов на Apple TV. Плагин не переводит пользователя на него автоматически. Нативный Luxo и его интерфейс на реальном устройстве здесь не проверялись.

При скрытии отсчёта Better Player штатная настройка Lampa `playlist_next` остаётся независимой. Плагин не меняет её. Без плейлиста серий перейти к следующей серии невозможно.

## Экспериментальная ветка функций: 1.1.0-beta.1

Код сохранён отдельно в `better-player-beta.js`. **Не загружайте оба файла одновременно**: они используют одну защиту инициализации. Для тестирования беты сначала удалите расширение стабильной версии, затем добавьте адрес беты и перезапустите приложение. Чтобы откатить, замените адрес обратно.

| Функция | Что действительно реализовано | Что остаётся |
|---|---|---|
| Автокачество | Внутренний плеер: потолок качества для известных вариантов; снижение после 15 секунд буферизации; ручной выбор отключает автоматику на текущий сеанс | Нативный Luxo; оценка скорости; повышение качества; управление адаптацией master HLS |
| Fallback | Внутренний плеер: при фатальной ошибке пробует меньшие качества того же видео, каждую ссылку один раз; сохраняет позицию | Переключение между провайдерами Mando; согласование серий и озвучки; обновление просроченных ссылок |
| Thumbnails | Загрузка WebVTT с изображениями и `#xywh`-спрайтами, показ при удержании; защита от запоздалого ответа предыдущего фильма | Получение или генерация кадров для Mando; нативный плеер |
| Netflix UI | Отключаемое тёмное оформление внутреннего плеера с красной шкалой | Полная замена UI и нативный Luxo |
| Персональные рекомендации | Отключаемая строка на главной по максимум четырём лайкам TMDB; сортировка по жанрам, совпадениям слов описания и языку; разнообразие и исключение просмотренного | Семантические эмбеддинги, негативные оценки, оценка качества выдачи и серверная синхронизация |

Автокачество, fallback, оформление и рекомендации в бете выключены по умолчанию. Это начальный алгоритм персонализации, **не алгоритм Netflix и не заявка на «самый современный»**. Из истории не делается вывод, что фильм понравился. Если нет лайков или TMDB не ответил, фальшивая «персональная» популярная подборка не подставляется.

Запросы кандидатов используют существующий TMDB API/прокси Lampa и передают ему идентификаторы выбранных лайков. Сортировка выполняется на устройстве; отдельного сервера Better Player пока нет. Карточки других каталогов не смешиваются с TMDB по совпадению числового ID.

### Договорённость для источника превью

Источник должен явно передать в объект `Lampa.Player.play`:

```js
better_player: {
    thumbnail_vtt: 'https://your-media-host.example/film/thumbnails.vtt'
}
```

Это новый контракт Better Player, **не подтверждённый API Mando**. VTT и изображения должны быть доступны приложению; для VTT нужен разрешённый CORS. Плагин не получает кадры из произвольного фильма, не загружает второй поток и не отправляет ссылки Mando на сторонний сервер. Ограничение VTT — 1 MiB / 10 000 кадров, таймаут 8 секунд.

### Следующие этапы

1. Для текущего Luxo сохранить настройки и собрать показания диагностики. Для изменения нативного плеера нужен документированный интерфейс Luxo или изменение самого приложения. Придумывать команды bridge нельзя.
2. Проверить строку персонализации в каталоге Luxo; затем добавлять явные оценки и семантическое сходство с измерением качества выдачи.
3. Для переключения провайдеров получить поддерживаемый Mando механизм выбора источника, с совпадением фильма/серии, версии монтажа и озвучки.
4. Для кадров выяснить наличие готовых VTT/storyboard у источника. Сервер нужен только при отсутствии кадров или для дополнительных функций, а не обязательно для любой персонализации.
